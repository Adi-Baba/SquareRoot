# SRS — The General Separation Bounds

Version 1.0. Self-contained proofs of the principal separation theorems,
written from base. Facts quoted from the literature are labelled QUOTED and
are not re-proved here. All logs are base 2.

Throughout, `S = Σ_{i=1}^m C_i sqrt(d_i)` with distinct squarefree
`d_i ≥ 2`, non-zero integer coefficients `C_i`, `r = log₂[Q(sqrt(d)):Q]`, and
`N` the input size (`N_real` unless a theorem says otherwise).

---

## 2.1 The trivial bound is effective: Liouville

**Theorem 2.1.** Let `S = Σ_{j=1}^k c_j sqrt(a_j) ≠ 0`, `|c_j| < 2^n`,
`0 < a_j < 2^n`. Then

```
log₂(1/|S|) ≤ (2^k − 1)·(3n/2 + log₂ k).
```

*Proof.* Four steps.

1. **`S` is an algebraic integer.** Each `sqrt(a_j)` is a root of the monic
   integer polynomial `x² − a_j`, hence an algebraic integer; the algebraic
   integers form a ring, so `S` is one. Its minimal polynomial over `Q` is
   monic with integer coefficients.

2. **Degree.** `S` lies in `K = Q(sqrt(d) : d ∈ D)`, the field generated by
   the aggregated squarefree parts. By the F₂-basis argument (`SRS_01`,
   Thm 1.2), `[K:Q] = 2^r ≤ 2^k`, hence `deg(S) ≤ [Q(S):Q] ≤ 2^k`.

3. **Conjugates.** Every embedding `σ : K ↪ ℂ` sends `sqrt(d_i)` to
   `±sqrt(d_i)` (the roots of `x² − d_i`), so `σ(sqrt(a_j)) = ±sqrt(a_j)` and

   ```
   |σ(S)| ≤ Σ_j |c_j| sqrt(a_j) < k · 2^n · 2^{n/2} = k·2^{3n/2}.
   ```

   `K/Q` is normal (the splitting field of `∏(x² − d_i)`), so every conjugate
   of `S` over `Q` is such a `σ(S)`, and the bound covers all of them.

4. **Norm.** `N_{Q(S)/Q}(S) = ∏ σ_i(S)` is a non-zero integer (`S ≠ 0`), so
   its absolute value is `≥ 1`. One factor is `S` itself; the other
   `deg(S) − 1 ≤ 2^k − 1` factors are each `< k·2^{3n/2}`. Hence

   ```
   1 ≤ |N(S)| ≤ |S|·(k·2^{3n/2})^{2^k − 1},
   ```

   i.e. `|S| ≥ (k·2^{3n/2})^{-(2^k−1)}`, and taking `log₂` gives the claim. ∎

*Direction.* This is a **guarantee**: no nonzero instance is smaller than
`(k·2^{3n/2})^{-(2^k−1)}`, i.e. `log₂(1/|S|)` is at most that.

## 2.2 Two terms: sharp constant

**Theorem 2.2.** Let `S = c₁ sqrt(a) + c₂ sqrt(b) ≠ 0` with integers
`c₁, c₂ ≠ 0`, `a, b ≥ 1`, and `N = log₂(|c₁|·a·|c₂|·b)`. Then

```
log₂(1/|S|) ≤ N/2 + 3/2.
```

*Proof.* Step 1 (squarefree reduction). Write `a = p²d`, `b = q²e` with
`d, e` squarefree; `S = C₁ sqrt(d) + C₂ sqrt(e)`, `C₁ = c₁p`, `C₂ = c₂q`.
Step 2. If `d = e`, `S = (C₁+C₂) sqrt(d)` is a single quadratic term,
`|S| ≥ sqrt(d) ≥ 1`, and the claim is trivial. Otherwise `d ≠ e`, `d, e`
squarefree, `sqrt(d)` and `sqrt(e)` are `Q`-linearly independent, and

```
|S| · | C₁ sqrt(d) − C₂ sqrt(e) | = | C₁²d − C₂²e | ≥ 1,
```

since `C₁²d − C₂²e` is a non-zero integer (it vanishes only if `d/e` is a
rational square, impossible for distinct squarefree `d, e`). The second factor
is `≤ 2M sqrt(max(d,e)·max|C|²) ≤ 2·sqrt(AB)` with `A = a`, `B = b`, so
`|S| ≥ 1/(2 sqrt(ab))`, i.e. `log₂(1/|S|) ≤ ½(log₂a + log₂b) + 1`. Now
`N/2 = ½(log₂|c₁| + log₂a + log₂|c₂| + log₂b) ≥ ½(log₂a + log₂b)`, giving
`log₂(1/|S|) ≤ N/2 + 1`. ∎

(A slightly larger constant `3/2` in the statement is harmless; the theorem
in the repo carries `3/2`. The exponent `1/2` on `N` is sharp.)

## 2.3 The achieved rate (pigeonhole)

**Theorem 2.3 (pigeonhole / achieved).** Let `d₁, …, d_r` be distinct
squarefree integers and `B ≥ 1`. There exist integers `C₁, …, C_r`, not all
zero, `|C_i| ≤ B`, with

```
|Σ_i C_i sqrt(d_i)| ≤ (Σ_i sqrt(d_i)) / B^{r−1},
```

hence `log₂(1/|S|) ≥ (r−1) log₂ B − O(1)`. With radicands fixed and
`|C_i| ≤ B`, the input size is `N ≍ r·log₂B`, so `E/N ≥ (r−1)/r − o(1)`.

*Proof.* Consider the `(B+1)^r` values `v(C) = Σ C_i sqrt(d_i)`,
`C ∈ {0, …, B}^r`. They are **pairwise distinct**: an equality `v(C) = v(C')`
would give a non-trivial rational relation among the `sqrt(d_i)`, forbidden by
independence (`SRS_01`, Cor 1.3). They all lie in `[0, B Σ_i sqrt(d_i)]`.
Sorting them, two consecutive values differ by at most
`B·Σ sqrt(d_i) / ((B+1)^r − 1) ≤ 2·(Σ sqrt(d_i))·B^{-(r−1)}`, and their
difference is a sum `Σ C_i sqrt(d_i)` with `|C_i| ≤ B`, `C ≠ 0`. ∎

*Remarks.*
- Tight at `r = 2`: Thm 2.2's sharp exponent `1/2` matches `(2−1)/2`.
  Two independent arguments give the same number, so `(r−1)/r` is the
  achieved ceiling.
- This is a pure counting argument; it cannot give arithmetic structure.
  It is realised as family F6 at `r = 3` (sort `{2,3,5}` coefficient sums,
  certify the gap exactly), which attains `E/N ≈ 2/3` from within.

## 2.4 The guaranteed rate: Subspace Theorem

**Theorem 2.4 (single-form Subspace Theorem — exponent `r−1`).** Fix distinct
squarefree `d₁, …, d_r`, put `α_i = sqrt(d_i/d_r)` (`i < r`), and

```
L(C) = C_r + Σ_{i<r} C_i α_i = S / (C_r sqrt(d_r)).
```

The `1, α_1, …, α_{r−1}` are `Q`-linearly independent (Cor 1.3). Then for
every `δ > 0` there exist `c = c(d₁,…,d_r,δ) > 0` and finitely many proper
rational subspaces `V₁, …, V_t ⊊ Q^r` such that, for every integer `C` outside
their union,

```
|L(C)| > c · ‖C‖^{−(r−1+δ)},
```

so, writing `m = log₂‖C‖_∞` and `N = r·m` (radicands fixed),

```
log₂(1/|S|) ≤ (r−1+δ)/r · N + O_{d,δ}(1).
```

*Proof.* Apply the Subspace Theorem in `r` variables to the `r` forms
`L_0 = L`, `L_i = C_i` (`1 ≤ i ≤ r−1`). They are linear over `Q̄` because
`1, α_1, …, α_{r−1}` are `Q`-independent. Points with
`|L(C)| · Π_{i<r}|C_i| ≤ ‖C‖^{−δ}` lie in a finite union of proper rational
subspaces. Since `Π|C_i| ≤ ‖C‖^{r−1}`, every `C` outside that union satisfies
`|L(C)| > ‖C‖^{−δ} / ‖C‖^{r−1} = ‖C‖^{−(r−1+δ)}`. ∎

**Status of `c(d,δ)`.** This is the exact missing theorem: `c` depends on the
radicands (input), so the bound is effective only for fixed radicands.
Thm 2.6/effective substitutes give `2^{r−1}−1` effective; Thm 2.4 gives the
sharp `r−1` exponent but an ineffective `c`.

## 2.5 Norm bounds and the degree obstruction

**Theorem 2.5 (norm bound).** With `S = Σ C_i sqrt(d_i)`, `r` the F₂-rank,
`M = max(‖C‖_∞, max_i d_i)`:

```
log₂(1/|S|) ≤ (2^{r−1} − 1)·(log₂ M + O(1)).
```

*Proof.* Take conjugates over `K = Q(sqrt(d_i))`, a `2^r`-fold Galois
extension. Group them into `2^{r−1}` pairs `{σ(S), τσ(S)}` with `τ` the
global sign flip. The pair-products are algebraic integers. Newton/product
of each pair is an integer; standard resultant elimination of the `C_i` gives
a non-zero integer polynomial of degree `2^r` with root `S`, sub-leading
coefficient sum bounded by `2^{r−1}` copies of `T = Σ|C_i| sqrt(d_i) ≤ 2^r M`,
and AM–GM bounds `|S|` below. ∎

**Theorem 2.5′ (squaring does not help).** `S²` has the same field and half
the degree over `Q`, but its rational part `Σ C_i²d_i` breaks the complement
pairing, so the resulting bound is unchanged: the factor count is still
`2^{r−1}−1` while `log₂ T` doubles. Hence squaring yields no improvement.

**Theorem 2.6 (the obstruction is the degree).**
`[Q(S):Q] = 2^r` exactly (when all `C_i ≠ 0`), so no norm argument can ever
reach `poly(r)`. Zeroing one `C_i` halves the degree to `2^{r−1}`, which is
sharp. This is why any effective `poly(r)` must come from an argument family
that is neither pure norm nor pure Subspace Theorem.

## 2.6 Corollaries and the effective-for-fixed-rank statement

**Corollary 2.6a (fixed rank is effective).** Fix `r`. Then
`log₂(1/|S|) ≤ (2^{r−1}−1)(N + O(log r))` from Thm 2.1 with `k = r`, which is
effective, so every fixed rank is settled.

**Corollary 2.6b (Subspace Theorem ranks `r = O(log N)`).** Combine Thm 2.4
(`r−1` exponent, ineffective `c`) with the effective constant at fixed rank.
For `r ≤ (K−1) log₂ N`, the Subspace bound plus a comparison to the effective
bound settles the conjecture in that band; the open band is
`O(log N) ≤ r ≤ N/2`. (Full justification in `THE_MISSING_THEOREM.md`.)

## 2.7 The retracted claims (record, not proof)

For the error log, two results previously stated in this line of files are
**false** and are retracted:

- **`sup E/N = (r−1)/r` over all `N`.** Counterexample: `r = 3`,
  `S = −10√2 − 98√3 + 51√13`, certified `|S| = 2.8318…×10⁻⁷`, so
  `E/N = 1.2795 > 2/3`. The correct sharp form is the limsup
  `limsup E/N = (r−1)/r`.
- **A general effective constant for `r ≤ 4`.** It relied on
  `dist(aW, ℤ) = a·dist(W,ℤ)` for a lattice `W`, which is false unless
  `aℤ = ℤ`. No effective `poly(r)` norm constant at `r = 4` is known.

## 2.8 What remains open

The uniform statement

```
c(d₁,…,d_r,δ) ≥ 2^{−poly(N)}     uniformly over all r, delta.
```

is the exact missing theorem. It is EHS Problem 33 and is open. All results
above are consistent with it; none prove it.
