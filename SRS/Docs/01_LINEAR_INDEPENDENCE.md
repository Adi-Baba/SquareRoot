# Paper A — Linear Independence, the Zero Test, and the Field Degree

Version 1.0. Three elementary results, all proved from the definitions:

- **Thm A.1** a single square root is never in a tower generated by
  independent ones;
- **Cor A.3** the zero test `S = 0` is correct;
- **Thm A.2** the field degree is exactly `2^r`, and a primitive element.

All are special cases of one induction.

---

## A.0 The F₂-independence setup

For a positive integer `t`, its **parity vector** `v(t)` is the map
`p ↦ (exponent of p in t) mod 2`, an element of the vector space of finitely
supported `{0,1}`-sequences under symmetric difference = addition over `F₂`.

A set `{t₁,…,t_r}` is **F₂-independent** when the `v(t_i)` are linearly
independent over `F₂`. Equivalently: no nonempty subproduct of the `t_i` is a
perfect square.

Write `v(1) = 0`, so `1` is dependent on the empty set and corresponds to the
rational term; it is handled separately.

---

## A.1 Thm A.1 — the irrationality step

**Theorem A.1.** Suppose `t₁,…,t_r` are positive integers with independent
parity vectors, and `s ≥ 1` is an integer such that
`{t₁,…,t_r,s}` also has independent parity vectors. Then

```
sqrt(s) ∉ Q(sqrt(t₁),…,sqrt(t_r)).
```

*Proof.* Induction on `r`.

*Base `r = 0`.* The field is `Q`. Since `s`'s parity vector is independent of
the empty set, `s` is not a perfect square, so `sqrt(s) ∉ Q`.

*Step.* By the induction hypothesis, `sqrt(t_r)` is not in
`F := Q(sqrt(t₁),…,sqrt(t_{r−1}))`, so `[F(sqrt(t_r)):F] = 2` and every
element of `F(sqrt(t_r))` has a unique form `a + b·sqrt(t_r)` with
`a, b ∈ F`. Suppose `sqrt(s) = a + b·sqrt(t_r)`. Squaring,

```
s = a² + b²t_r + 2ab·sqrt(t_r).
```

Since `sqrt(t_r) ∉ F`, the coefficient of `sqrt(t_r)` vanishes: `2ab = 0`.

- `b = 0`: then `sqrt(s) = a ∈ F`, contradicting the induction hypothesis
  that `s` is independent of `t₁,…,t_{r−1}`.
- `a = 0`: then `sqrt(s) = b·sqrt(t_r)`, so `s/t_r = b²` is a square in `F`,
  i.e. `v(s) − v(t_r)` lies in the `F₂`-span of `v(t₁),…,v(t_{r−1})`, so
  `v(s)` lies in the span of `v(t₁),…,v(t_r)` — contradiction.

Both impossible, so `sqrt(s) ∉ F(sqrt(t_r))`. ∎

## A.2 Corollary A.2 (independence and degree)

**Corollary A.2.** Let `d₁,…,d_r` be distinct squarefree integers `≥ 2` with
independent parity vectors. Then `{sqrt(d₁),…,sqrt(d_r)}` is linearly
independent over `Q`, and

```
[Q(sqrt(d₁),…,sqrt(d_r)) : Q] = 2^r.
```

*Proof.* Each step adjoining `sqrt(d_i)` either keeps the field (impossible by
Thm A.1 unless `d_i` is a rational square, which squarefree `≥ 2` forbids) or
doubles it. All `r` steps are degree-2 extensions, so the degree is `2^r`.
Linear independence of the `sqrt(d_i)` follows: a rational relation
`Σ C_i sqrt(d_i) = 0` with some highest index `j` active and `d_j`
independent of the earlier ones gives `sqrt(d_j)` in the field generated by
the others, contradicting Thm A.1. ∎

**Corollary A.2′ (the general field degree).** For arbitrary squarefree
`d₁,…,d_m`, take a maximal `F₂`-independent subset `{d_{i₁},…,d_{i_r}}`.
Every other `d` is a product of a subset of them modulo squares, so its square
root already lies in `K := Q(sqrt(d_{i₁}),…,sqrt(d_{i_r}))`. Hence `K` is the
full generated field and `[K:Q] = 2^r`. So the rank `r` is exactly the
log₂-degree. ∎

## A.2b Theorem A.3 — distinct squarefree radicals are always independent

The hypothesis "independent parity vectors" in Cor A.2 is what makes the
*degree* `2^r`. For the *zero test* we need something weaker and more general:
the square roots of *any* set of distinct squarefree integers are linearly
independent over `Q`, even when their parity vectors are dependent. (Example:
`2, 3, 6` have `v(6) = v(2)+v(3)`, F₂-rank `2 < 3`, yet
`√2, √3, √6` are `Q`-independent.)

**Theorem A.3.** Let `D` be a finite set of distinct squarefree positive
integers. Then `{√d : d ∈ D}` is linearly independent over `Q`.

*Proof.* Induction on the number of distinct prime factors of
`Π_{d∈D} d`.

*Base (no primes).* Every `d ∈ D` equals `1`, so `D = {1}`, and the set is
`{1}`, independent.

*Step.* Pick a prime `p` dividing some member of `D`. Write each
`d = p^{e(d)}·m(d)` where `e(d) ∈ {0,1}` (squarefree) and `p ∤ m(d)`. Split
the putative relation `Σ_{d∈D} C_d √d = 0` by the parity of `e(d)`:

```
A := Σ_{d: e(d)=0} C_d √m(d),      B := Σ_{d: e(d)=1} C_d √m(d),
Σ C_d √d = A + √p · B = 0.
```

Both `A, B` lie in `F := Q(√m(d) : d ∈ D)`, a field generated by square roots
of integers `m(d)` none of which is divisible by `p`, so `p` contributes a
*new* prime not appearing in any `m(d)`. A maximal `F₂`-independent subset of
those `m(d)` spans them modulo squares, and `v(p)` is independent of that
subset (it has a `1` in the `p`-coordinate, all of them have `0` there). By
Thm A.1, `√p ∉ F`. Hence `A + √p·B = 0` in the degree-`2` extension
`F(√p)/F` forces `A = 0` and `B = 0`.

Each is a relation over squarefree integers all dividing
`Π d / p^{Σ e(d)}`, which has strictly fewer prime factors than `Π d`. By the
induction hypothesis, all coefficients in `A` vanish and all coefficients in
`B` vanish. Hence every `C_d = 0`. ∎

This is the fact the zero test and the pigeonhole argument need; Cor A.2 of
the `2^r` degree is a separate, stronger statement about the *independent*
case.

## A.3 Cor A.3 — the zero test

**Cor A.3 (zero test).** Let `S = Σ_d C_d·sqrt(d)` over distinct squarefree
`d ≥ 1`. Then `S = 0` iff every `C_d = 0`.

*Proof.* Decompose `C_0` (the `d=1` part) separately. The remaining radicals
are `Q`-linearly independent by Thm A.3. A rational relation with `C_d ∈ Z` is
a `Q`-relation, so every non-rational coefficient must vanish. Coefficients
are integers, so vanishing means `C_d = 0`. ∎

Algorithmically: decompose each radicand `a_j = t_j²·d_j`, aggregate the
`d_j`, and check every aggregate coefficient is `0`. Polynomial time.

## A.4 Primitive element

**Proposition A.4 (primitive element).** `K = Q(sqrt(d₁),…,sqrt(d_r))` has a
primitive element, e.g. `γ = sqrt(d₁) + sqrt(d₂) + … + sqrt(d_r)` whenever the
empty product of a nontrivial subset is not ±1. Consequently `K = Q(S)` for
generic `S`, and `[Q(S):Q] = 2^r`.

*Proof.* The degree is `2^r`; the conjugates of `γ` are
`Σ ±sqrt(d_i)` over all `2^r` sign choices. Two sign choices give the same
value only if `Σ ε_i sqrt(d_i) = 0` for some non-zero `ε ∈ {−2,0,2}^r`,
i.e. a rational dependence — excluded by Thm A.3, except the degenerate
cases `γ = ±sqrt(d_i)` (single term) or trivial `γ = 0`. So all `2^r`
conjugates are distinct and `[Q(γ):Q] = 2^r`, hence `Q(γ) = K`. ∎

*Consequence.* `[Q(S):Q] = 2^r` whenever no conjugate of `S` is fixed, i.e.
for all but a finite union of hyperplanes in the coefficients `C_i`. This is
the degree fact that drives the norm argument of Paper B.

---

## A.5 What this buys us

Every later paper uses two consequences:

1. `[K:Q] = 2^r` — the norm `N_{K/Q}` has `2^r` factors.
2. The radicals are `Q`-linearly independent — the zero test is a matter of
   checking integers, and the imaginary tower is non-degenerate.
