## Conventions

**Instance.** `S = Σ_{i=1}^{m} C_i·√d_i`, integers `C_i ≠ 0`, distinct
squarefree `d_i ≥ 1` (with `d_i = 1` the rational part, absorbed into a
constant `C_0`; we usually omit it).

**Rank.** `r = log₂ [Q(√d_1, …, √d_m) : Q]`. By Paper A, `2^r` is the field
degree. This is the number of *independent* quadratic generators, not the
number of terms.

**Input size `N`.** Two conventions are used, never silently swapped:

- *Real*: `N = Σ_i (log₂|C_i| + log₂ d_i)`.
- *Bit length*: `N_bits = Σ_i (bitlen|C_i| + bitlen d_i)`.

Because `bitlen x ∈ (log₂ x, log₂ x + 1]`, we have `N ∈ (N_real, N_real + 2m]`.
Every rate statement transfers between them with additive `O(m)` slack, i.e.
an `O(1/N)` relative difference. Each theorem names the one it uses.

**Exponent.** `E := log₂(1/|S|)` for `S ≠ 0`; `E/N` is the separation rate.

**Markov/badly-approximable constant.** `λ(α) := inf_{q ≥ 1} q·‖qα‖`, where
`‖·‖` is distance to the nearest integer. This is the *separation* constant,
i.e. the largest `c₀` with `|qα + p| ≥ c₀/q` for every `p, q`.

## One-paragraph summary of the math

- Zero test: decide `S = 0` in P (Paper A, Cor A.3).
- Every fixed rank is effective (Paper B): `E ≤ (2^{r−1}−1)(N + O(log r))`.
- The Subspace Theorem gives the sharp asymptotic exponent `r − 1` (Paper C),
  but with an ineffective constant `c(d,δ)` — that one constant is the whole
  remaining gap.
- `r = 2` needs no constant at all (Paper D and Paper E): the effective bound
  `log₂(1/|S|) ≤ N/2 + 3/2` holds outright.
- The Pell family saturates a known `1/4`-of-`N` two-sided law (Paper E).
- For `r ≥ 4`, no effective `poly(r)` constant is known; every norm-based
  attempt has failed (Paper F), and the one false `r ≤ 4` claim was retracted
  (Paper F and Paper 7).
- The conjecture `E ≤ poly(N)` uniformly across all `r` is OPEN (Paper F).
